# Google Ads Campaign Performance and Sales Analytics Using Python

A data analytics portfolio project focused on evaluating advertising campaign performance and its relationship with sales using Python.

## Project Scope

The project is designed around an end-to-end analytics workflow:

- Data inspection and quality checks
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Descriptive and statistical analysis
- Campaign and sales performance analysis
- Matplotlib and Seaborn visualizations
- Business-focused observations and presentation

## Tools & Skills

`Python` • `Pandas` • `NumPy` • `Matplotlib` • `Seaborn` • `EDA` • `Data Cleaning` • `Data Visualization` • `Data Storytelling`

## Repository Status

This repository has been set up as the portfolio home for the Google Ads Campaign Performance and Sales Analytics project. Project assets should be kept here together so recruiters can review the source dataset, analysis notebook, and presentation from one location.
